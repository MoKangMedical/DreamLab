## 小红书首批笔记

### D1 梦见被追赶

标题：总是梦见被追赶，是不是潜意识在提醒你？

封面：梦见被追赶，先别急着害怕

图文卡：

1. 先看梦里的身体感受：喘不过气、跑不动，还是一直找不到出口？
2. 再看现实里的压力：是否有一个问题你一直拖着不处理？
3. 不要直接查“吉凶”，先记录：人物、地点、情绪、醒后感受。
4. 梦境解析不是诊断，它更像一次自我观察。
5. 记录 7 天后，再看重复出现的主题。

正文：我更建议把梦当成一份夜间情绪材料，而不是预言。DreamLab 可以先帮你把梦拆成主题、情绪和可学习课程。

CTA：主页进 DreamLab，先做一次梦境记录。

标签：`梦境解析` `心理学` `自我成长` `睡眠`

链接：`/start?utm_source=xhs&utm_medium=note&utm_campaign=dream_chase`

### D2 焦虑自查

标题：焦虑不是你太脆弱，可能是系统已经过载

封面：焦虑时，先检查这 3 个信号

图文卡：

1. 睡眠是否变浅：入睡慢、易醒、醒后累。
2. 身体是否变紧：肩颈、胃部、胸口或下颌。
3. 大脑是否反复预演最坏结果。
4. 先记录，不急着评价自己。
5. 轻量测评能帮你找到下一步学习入口。

正文：焦虑感出现时，最容易做的是责备自己；更有效的是把它拆成可观察的身体和念头信号。

CTA：主页做一次心理测评，生成你的第一张观察图。

标签：`焦虑自救` `心理测评` `情绪管理` `DreamLab`

链接：`/start?utm_source=xhs&utm_medium=note&utm_campaign=anxiety_check`

### D3 课程入口

标题：心理学入门别硬啃教材，先从一个真实问题开始

封面：100 门心理课，先学哪 3 门？

图文卡：

1. 梦境困扰：先学弗洛伊德、荣格、睡眠科学。
2. 情绪困扰：先学 CBT、正念、情绪调节。
3. 关系困扰：先学依恋、沟通、家庭系统。
4. 拖延困扰：先学动机、习惯、时间知觉。
5. 每学一节课，都写一句今天能做的小动作。

正文：DreamLab 的课程不是为了堆知识，而是把一个真实问题变成一条可复盘的成长路线。

CTA：主页进入 100 门课程地图。

标签：`心理学入门` `课程推荐` `成长路线` `学习方法`

链接：`/start?utm_source=xhs&utm_medium=note&utm_campaign=course_route`

### D4 睡前关机句式

标题：睡前反复想事的人，试试这句“关机句式”

封面：睡前大脑停不下来，先写这一句

图文卡：

1. 我现在最担心的是：____。
2. 这件事明天最小一步是：____。
3. 今晚我允许自己先休息，因为：____。
4. 写完就停，不继续推演。
5. 第二天再用反思日志复盘。

正文：睡前不是解决人生问题的最佳时段。先把问题交给明天的行动，而不是交给今晚的焦虑。

CTA：去 DreamLab 写一条反思日志。

标签：`睡眠` `反思日志` `心理工具` `情绪稳定`

链接：`/start?utm_source=xhs&utm_medium=note&utm_campaign=sleep_shutdown`

## 合规检查

1. AI 图文、音频、视频和数字人口播必须显式标识，不隐藏或移除平台标识。
2. 虚拟案例必须标注为改编/虚构/综合案例，不伪造真人经历、聊天截图或疗效证明。
3. 不使用“治愈、诊断、根治、保证改善”等医疗效果承诺。
4. 涉及危机、创伤、自伤等主题时，提供寻求专业帮助的提醒。
5. 数字人不冒充真人咨询师，不使用未授权真人肖像、声音或专家身份。
6. 所有 CTA 指向教育、记录、测评、课程和复盘，不引导用户替代线下专业服务。
