# DreamLab 数字人宣传制作交付包

## 固定设定

角色：DreamLab AI 心理研究员

定位：心理学教育、自我观察、课程导读、练习引导和产品说明。

不得使用的表达：

- 我是你的心理咨询师
- 我能诊断你的问题
- 这个方法可以治愈/根治/保证改善
- 不需要寻求专业帮助

固定标识：

- 画面角落：`AI 数字人口播 · 心理学教育内容`
- 结尾字幕：`内容仅用于心理学教育与自我观察，不替代专业诊断或治疗`
- 如平台提供 AI 标识开关，发布时必须开启。

## 视觉规范

画幅：1080x1920，竖屏。

背景：

- 深色底：`#0a0a0c`
- 金色强调：`#d4a853`
- 面板：`#111113`
- 字体建议：思源宋体 / Noto Serif SC / 系统宋体

数字人构图：

- 半身像居中或右侧 45% 区域。
- 左侧出现关键词卡片。
- 全程保留 DreamLab 品牌露出。
- 不使用真实咨询室、白大褂、医院、诊疗暗示画面。

导出：

- 视频：MP4，1080x1920，25 或 30fps。
- 音频：普通口播即可；如后期统一，使用 `loudnorm=I=-16:TP=-1.5:LRA=9`。
- 字幕：白字为主，关键词用金色。

## EP01 DreamLab 心理研究员开场

目的：建立品牌定位，说明边界，承接 `/start`。

时长：35-45 秒。

画面：

1. 0-3 秒：DreamLab 标识 + 数字人出现。
2. 3-15 秒：左侧出现“梦境解析 / 心理测评 / 100 门课程 / 成长复盘”。
3. 15-32 秒：数字人解释 DreamLab 是心理学学习与自我观察实验室。
4. 32-45 秒：出现 CTA。

口播：

你好，我是 DreamLab 的 AI 心理研究员。这里不是诊断室，而是一间心理学学习与自我观察实验室。你可以从一个梦、一次测评、一段反思开始，慢慢建立自己的心智成长路线。进入主页，完成第一次 3 分钟体验。

字幕重点：

- 不是诊断室
- 心理学学习与自我观察
- 3 分钟开始

CTA：

主页进入 DreamLab，完成第一次 3 分钟体验。

## EP02 弗洛伊德如何看梦

画面：

1. 0-3 秒：梦境剧场背景 + 问题钩子。

3. 18-32 秒：四张卡片：情绪、人物、场景、压力。

字幕重点：

- 梦不是固定符号表

CTA：

记录一个最近印象最深的梦。

画面：

字幕重点：

- 阴影不是缺点
- 未被整合的部分

CTA：
