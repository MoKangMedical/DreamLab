# DreamLab 小程序上线清单

## 本地准备

- [ ] `project.config.json` 中的 `appid` 已替换为正式小程序 AppID。
- [ ] `npm install` 已完成。
- [ ] `npm run build:weapp` 构建通过。
- [ ] 微信开发者工具导入 `miniapp`，编译模式为普通编译。
- [ ] 首页、课程、测评、解梦、反思、我的页面可以正常打开。

## 微信公众平台配置

- [ ] 小程序名称、头像、简介、类目已填写。
- [ ] 服务类目建议使用心理健康教育/工具相关类目，避免宣传诊断、治疗、疗效承诺。
- [ ] 服务器域名已配置：
  - [ ] `request` 域名：`https://MoKangMedical.github.io`
  - [ ] 如启用后端，再添加正式 HTTPS API 域名。
- [ ] 隐私保护指引已填写：
  - [ ] 说明本地保存梦境、反思、测评进度等用户主动输入内容。
  - [ ] 如启用后端，说明数据会上传用于生成分析结果。
- [ ] 用户协议和隐私政策页面已准备。

## 审核材料

- 小程序名称：DreamLab
- 版本号建议：`1.0.0`
- 版本描述建议：
  `DreamLab 首个小程序版本，提供心理课程、心理测评、梦境解析、反思日志和个人成长档案。内容仅用于心理学教育和自我观察，不替代专业诊断或治疗。`
- 审核备注建议：
  `本版本为心理学教育与自我观察工具。课程数据来自项目 GitHub Pages 静态资源；梦境解析与反思日志默认本地生成/保存，不提供医疗诊断、治疗建议或疗效承诺。`

## 发布流程

1. 微信开发者工具打开 `miniapp`。
2. 确认右上角 AppID 为正式 AppID。
3. 点击“上传”，填写版本号和项目备注。
4. 微信公众平台进入“版本管理”。
5. 将开发版本提交审核。
6. 审核通过后点击“发布”。
